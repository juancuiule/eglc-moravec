## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (juancuiule/eglc-moravec), using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default canonical label vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `CONTEXT.md` + `docs/adr/`. See `docs/agents/domain.md`.

### Design docs

Any change to `apps/frontend` UI must follow root `DESIGN.md` (tokens, layout,
motion, accessibility, anti-patterns). Keep it in sync with the code it cites.
